# SaaS E-commerce Analytics - Project Brief

## Project Name
**E-commerce Analytics SaaS**

## Location
`E:\Antigravity Projects\e-commerce-analytics-saas`

## Description
Plataforma donde dueño de tienda online conecta su base de datos y obtiene Dashboard con:
- Predicciones de ventas
- Análisis de stock crítico
- Segmentación de clientes VIP
- Customer Lifetime Value (CLV)

## Requirements ($50k Standard)

### 1. Supabase Schema
- Tablas para miles de transacciones
- View compleja para calcular CLV
- Índices optimizados para analytics
- RLS ultra estricto

### 2. UI/UX - Liquid Luxury
- Gráficos interactivos (Recharts/Tremor)
- Glassmorphism extremo
- Modo oscuro futurista
- Dashboard profesional

### 3. Security
- RLS por tenant
- Datos de ventas completamente aislados
- Autenticación robusta

### 4. Portfolio
- Mockup final con gráficos destacados
- Card para portfolio

## Stack
- Next.js 14 (App Router)
- Supabase (PostgreSQL)
- Recharts / Tremor
- Tailwind CSS
- TypeScript
